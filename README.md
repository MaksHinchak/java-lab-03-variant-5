## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab03** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab03_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Завдання 1: введи назву, адресу й спеціальну кількість для трьох організацій. Покажи, що один цикл викликає різні Show.
2. Завдання 2: a=5,b=3,x=5. Обидві криві дають y=0. Повтори з x=4: еліпс дає 1.8, гіпербола повідомляє про область визначення.
3. Завдання 3: ті самі параметри. Поясни, чому результат той самий, хоча зв’язок класів інший.

## Уточнення умови

- Для кривих прийнято a>0,b>0, канонічні рівняння з центром у початку координат і верхню гілку y>=0.
- У методичці написано equal; правильний стандартний метод Java має сигнатуру equals(Object). Саме його перевизначено.
- Класи організацій зберігаються також у лабораторній 7 як власники автопарків; копії моделей у репозиторіях забезпечують незалежний запуск.
